# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 版本历史与分支

编辑器把每一次改动保存成一个**完整快照**（而不是补丁），因此任何版本都可以单独恢复。

- **一次手势 = 一个版本**：拖动对象、拖拽锚点/控制柄、画笔描边都用 pointerdown/pointerup 包成一个手势；中间的 pointermove 不会产生多余版本。滑杆、颜色、数字输入等连续编辑会按属性合并，停顿后再落成一个版本。
- **撤销后再编辑**：撤销掉的后续操作不会丢失，而是自动保留为一条新分支（如 `main (undone)`）。每条分支都有独立的 redo 栈，切换分支不会互相影响。
- **分支与命名版本**：右侧 History 面板可以给当前版本命名（Pin）、重命名分支、从当前版本 Fork 新分支。命名版本不会被清理逻辑删除，跨分支也能找到。
- **恢复预览**：点击任意版本或分支的 Preview 会先做对比，再决定是否恢复。对比会逐项检查锚点与控制柄坐标、外观（填充、描边、粗细、透明度、闭合、分组）以及图层叠放顺序，而不是只看对象数量。恢复失败（目标丢失、数据损坏、嵌套异常）时文档、分支指针和 redo 栈都会回滚，当前工作保持不变。
- **导出**：始终读取当前已确认分支的最新版本；未提交的手势会先落成版本，未确认的预览不会影响导出。
- **持久化**：整个版本图（全部分支、redo 栈、命名版本）和一个未提交草稿都写入 `localStorage`，刷新后分支关系与命名版本仍然存在，草稿会恢复为一个 `Recovered unsaved work` 版本。旧版的单状态存档会自动迁移并保留原始数据（`forma-document-legacy`）。

## 存储清理

`src/features/history/lib/prune.ts` 在每次保存时压缩历史：优先丢弃最旧的、仅存在于 redo 栈中的版本，再丢弃最旧的未受保护版本。分支头、fork 点、命名版本及其快照始终保留；被剪掉祖先的版本只是把 `parent` 置空并标记 `truncated`，自身快照完整，仍可恢复。
